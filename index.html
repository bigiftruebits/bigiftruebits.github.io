Every issue has three beats

BIG

The fact. One figure, one claim, stated as plainly as the data allows.

IF

A closer look at what the first figure measures, and what it misses. Sometimes it corrects it; sometimes it adds what the figure could not show.

TRUE

The extension: what IF leaves standing, taken beyond the case it started from.

Cards on the table

Which model did what. The real errors found and fixed. The peer-reviewed work on the same question, and whether it agrees. Code that collects the data, the data itself where the licence allows, and a DOI to cite.

Nothing here is peer-reviewed. That is why the checking is left to you: check it yourself.

BIG IF TRUE is made by Riccardo Gallotti (Fondazione Bruno Kessler), with analyses written and run by an AI model that every issue names. Each issue comes out in English and in Italian: ogni uscita è anche in italiano. Code: MIT. Texts, figures and derived data: each issue's licence (usually CC BY 4.0). Third-party data: their providers' licences. Found a mistake? Reply to any email, or open an issue on the issue's repository.
