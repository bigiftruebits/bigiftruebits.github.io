Cards on the table

1Collection code: scripts re-download every raw input from its public source.
2Analysis code: scripts turn collected data into the numbers in the text.
3Figure code: scripts redraw each figure from processed data.
4This site: full-resolution figures, and interactive versions where the printed one was simplified.

Raw data is not stored in the repository; it is fetched by the scripts. Where something cannot yet be reproduced, the issue page says so.
