# BIG IF TRUE — project website

Source of https://bigiftruebits.github.io/ : home, manifesto (English and Italian), about, issues archive and how to check an issue.
Each issue's code, data pointers and figures live in its own repository (`bit-001-tropical-nights`, …), with figures in that repository's `docs/` folder, served at `bigiftruebits.github.io/<repo>/`.

Pages: `index.html`, `manifesto.html`, `about.html`, `issues.html`, `replicate.html`. Plain HTML and CSS, no build step. To add an issue: add a card in `index.html` and a row in `issues.html`.
